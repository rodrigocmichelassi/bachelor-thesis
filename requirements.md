## Setup

**Add text to how to setup Conda env with dependencies**

Create a `config.yaml` file in the project root, based on the `config.example.yaml`. 

Modify the `config.yaml` `raw_data.dataset_dir` with the path where BRSET was downloaded in your local machine.

The detection models used `optic-disc-detection.pt` and `fovea-detection.pt` will be made available upon demand. Please request access directly via email: <rodrigo.michelassi@usp.br>.
